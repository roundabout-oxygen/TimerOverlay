================================================================================
  Timer Overlay - ゲーム・画面 残り時間 最前面オーバーレイツール (v1.1.5)
================================================================================

【ソフト概要】
ゲーム（ブルーアーカイブ等）の戦闘画面や各種ゲーム・画面の「残り時間（タイマー）」を
リアルタイム（遅延約0.05ms/frame）にトリミングし、画面中央下などお好みの位置へ
最前面・角丸枠なし（四隅完全透過）で表示する超軽量オーバーレイツールです。

0.00秒単位の激しいカウントダウンも実画面と完全に一致して滑らかに追従します。
インストール不要、わずか約25KBで単体動作するWindowsネイティブ仕様です。


--------------------------------------------------------------------------------
■ 起動方法
--------------------------------------------------------------------------------
1. 「timer_overlay.exe」をダブルクリックして起動します。
   ※追加のランタイムやインストーラーは一切不要です（Windows 10/11 標準機能で動作）。


--------------------------------------------------------------------------------
■ 初回起動時（トリミング範囲の指定）
--------------------------------------------------------------------------------
1. 起動すると画面全体が薄暗くなり「トリミング範囲指定モード」になります。
2. ブルアカ等のゲーム画面を開き、右上の「残り時間（0.00s）」の部分を
   マウスの【左ドラッグ】で四角く囲んでください。
   ・ドラッグ中の範囲が鮮やかなシアン色の枠線とサイズ情報でハイライトされます。
   ・カーソル付近に「4倍拡大ルーペ」と十字線が表示されるため、
     タイマーの枠にピクセル単位で正確に合わせることができます。
3. マウスを離すと範囲が保存され、画面中央下にオーバーレイが表示されます。
   ※やり直したい場合は [Esc] キーまたは右クリックでキャンセルできます。


--------------------------------------------------------------------------------
■ 基本操作
--------------------------------------------------------------------------------
【移動】
  ・オーバーレイウィンドウのどこでも【左ドラッグ】すると、
    画面内の好きな場所（画面中央下、画面端など）へ移動できます。
  ・移動した位置は自動保存され、次回起動時も同じ位置に表示されます。

【ボタンの自動表示/非表示（v1.1.5新機能）】
  ・クリックしてアクティブになっている間のみ、右上の [×] と左上の [📐] ボタンが表示されます。
  ・他のソフトを操作中（非アクティブ時）はボタンが自動的に非表示になり、
    トリミングされたタイマー領域が遮られることなく隅々まで綺麗に映ります。

【終了】
  以下のいずれかの方法でいつでも確実に終了できます：
  1. オーバーレイをアクティブにして右上の [×] ボタンをクリック
  2. タスクバーのアプリアイコンを右クリック →「ウィンドウを閉じる」
  3. オーバーレイを右クリック →「❌ アプリを終了」
  4. フォルダ内の「stop.bat」をダブルクリック（緊急終了バッチ）

【設定メニュー（右クリック）】
  オーバーレイの上で【右クリック】すると設定メニューが開きます：
  ・📐 トリミング範囲を再設定 (F9) … いつでも範囲を取り直せます
  ・多重起動 ▷ 黄枠 / 赤枠        … 黄色枠・赤色枠の追加オーバーレイを表示/非表示
  ・🔍 表示倍率                   … 100% / 125% / 150% / 175% / 200%
  ・⚡ 更新レート (FPS)           … 30 / 60 / 90 / 120 FPS
  ・📍 位置を画面中央下にリセット … デフォルト位置に戻す
  ・ℹ️ バージョン: v1.1.5          … 現在のバージョン情報
  ・❌ アプリを終了               … すべてのオーバーレイを一括終了する

【多重起動モードについて（v1.1.5新機能）】
  ・右クリック ➜「多重起動」から「黄枠」「赤枠」を選択できます。
  ・選ぶとチェックが入り、1個目と同じ領域・サイズで少し下に黄枠/赤枠のオーバーレイが表示されます。
  ・各オーバーレイは個別にドラッグ移動が可能です。
  ・再度メニューで選ぶとチェックが外れて枠が消えます。
  ・「❌ アプリを終了」を選択すると、開いている全ての枠が一括で終了します。

【ショートカットキー】
  ・[F9] キー：いつでもトリミング範囲の再指定画面を呼び出せます。
               （オーバーレイ左上の [📐] ボタンを押しても同様に呼び出せます）


--------------------------------------------------------------------------------
■ ファイル構成
--------------------------------------------------------------------------------
・timer_overlay.exe     : アプリ本体（わずか約25KB・単体動作）
・stop.bat              : 万が一の際に一撃で完全終了できる緊急停止スクリプト
・config.json           : 設定保存ファイル（初回起動時に自動生成）
・readme.txt            : 本説明書


--------------------------------------------------------------------------------
■ 設定の初期化（リセット）について
--------------------------------------------------------------------------------
トリミング範囲や表示位置を最初からやり直したい場合は、
同じフォルダにある「config.json」を削除してから「timer_overlay.exe」を起動すると、
初期状態（範囲選択モード）から再スタートできます。
