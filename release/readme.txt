================================================================================
  Timer Overlay - ゲーム・画面 残り時間 最前面オーバーレイツール (v1.1.11)
================================================================================

【ソフト概要】
ゲーム（ブルーアーカイブ等）の戦闘画面や各種ゲーム・画面の「残り時間（タイマー）」を
リアルタイム（遅延約0.05ms/frame）にトリミングし、画面中央下などお好みの位置へ
最前面・角丸枠なし（四隅完全透過）で表示する超軽量オーバーレイツールです。

さらに、任意の静止画（PNG / JPG / BMP / GIF）の読み込み表示や、現在表示されている
トリミング画像の100%原寸保存、枠端のマウスドラッグによる自由なリサイズ（アスペクト比完全固定）
など多彩な機能を搭載しています。

0.00秒単位の激しいカウントダウンも実画面と完全に一致して滑らかに追従します。
デュアルディスプレイ（マルチモニター）環境にも完全対応し、隣のディスプレイの領域指定や
別モニターへのオーバーレイ配置もシームレスに行えます。
インストール不要、わずか約40KBで単体動作するWindowsネイティブ仕様です。


--------------------------------------------------------------------------------
■ 起動方法
--------------------------------------------------------------------------------
1. 「timer_overlay.exe」をダブルクリックして起動します。
   ※追加のランタイムやインストーラーは一切不要です（Windows 10/11 標準機能で動作）。


--------------------------------------------------------------------------------
■ 初回起動時（トリミング範囲の指定）
--------------------------------------------------------------------------------
1. 起動すると画面全体（全モニター）が薄暗くなり「トリミング範囲指定モード」になります。
2. ブルアカ等のゲーム画面を開き、右上の「残り時間（0.00s）」の部分を
   マウスの【左ドラッグ】で四角く囲んでください。
   ・ドラッグ中の範囲が鮮やかなシアン色の枠線とサイズ情報でハイライトされます。
   ・カーソル付近に「4倍拡大ルーペ」と十字線が表示されるため、
     タイマーの枠にピクセル単位で正確に合わせることができます。
   ・デュアルディスプレイ環境でも、隣のモニター上をそのままドラッグして指定可能です。
3. マウスを離すと範囲が保存され、画面中央下にオーバーレイが表示されます。
   ※やり直したい場合は [Esc] キーまたは右クリックでキャンセルできます。


--------------------------------------------------------------------------------
■ 基本操作
--------------------------------------------------------------------------------
【移動 ＆ 枠端ドラッグによるアスペクト比固定リサイズ】
  ・【移動】オーバーレイの内側（中央付近）を【左ドラッグ】すると、画面内の好きな場所へ移動できます。
    移動した位置は自動保存され、次回起動時も同じモニター・同じ位置に表示されます。
  ・【端ドラッグリサイズ (NEW!)】枠をクリックしてアクティブにした状態で、枠の端（四辺・四隅）に
    マウスを合わせるとリサイズカーソルに変化します。そのまま【左ドラッグ】することで、
    トリミング範囲の**アスペクト比（縦横比）を完全固定したまま自由にサイズ変更**できます！
    変更されたサイズ・倍率は自動的に保存されます。

【ボタンの自動表示/非表示】
  ・クリックしてアクティブになっている間のみ、右上の [×] と左上の [📐] ボタンが表示されます。
  ・他のソフトを操作中（非アクティブ時）はボタンが自動的に非表示になり、
    トリミングされたタイマー領域が遮られることなく隅々まで綺麗に映ります。

【終了】
  以下のいずれかの方法でいつでも確実に終了できます：
  1. オーバーレイをアクティブにして右上の [×] ボタンをクリック（サブ枠は個別終了）
  2. タスクバーのアプリアイコンを右クリック →「ウィンドウを閉じる」
  3. オーバーレイを右クリック →「❌ アプリを終了」（全枠一括終了）
  4. フォルダ内の「stop.bat」をダブルクリック（緊急終了バッチ）

【設定メニュー（右クリック）】
  オーバーレイの上で【右クリック】すると設定メニューが開きます：
  ・多重起動 ▷ 黄枠 / 赤枠        … 黄色枠・赤色枠の追加オーバーレイを表示/非表示
  ・📐 トリミング範囲を再設定   … [枠色ハイライト] クリックした枠の領域を個別に再設定
  ・🔍 表示倍率                   … [枠色ハイライト] 50%〜200%（現在の実倍率も表示、枠ごとに独立）
  ・⚡ 更新レート (FPS)           … [枠色ハイライト] 30 / 60 / 90 / 120 FPS（枠ごとに独立）
  ・💾 現在のトリミング画像を保存 … [枠色ハイライト] 表示中の画像・キャプチャを100%原寸で保存 (NEW!)
  ・🖼️ 静止画を読み込み...      … [枠色ハイライト] 任意の画像（PNG/JPG/BMP/GIF）を選択して表示
  ・🎥 画面キャプチャに戻す     … [枠色ハイライト] 静止画表示から元のリアルタイム画面キャプチャに復帰
  ・ℹ️ バージョン: v1.1.11         … 現在のバージョン情報
  ・❌ アプリを終了               … すべてのオーバーレイを一括終了する
  ※各枠（青・黄・赤）で右クリックすると、その枠に対応した淡いテーマカラーが
    操作項目に着色され、どの枠の設定を変更しているかが視覚的に一目でわかります。

【画像の保存と静止画読み込み機能】
  ・「💾 現在のトリミング画像を保存」を選択すると、現在枠内に表示されている画面キャプチャまたは
    静止画を【100%原寸サイズ】のままPNG/JPG/BMP形式でファイル保存できます。
  ・「🖼️ 静止画を読み込み...」から画像を選択すると、キャプチャの代わりに画像が最前面に表示されます。
    静止画表示中も端ドラッグリサイズや表示倍率による拡大縮小が可能で、CPU/GPU負荷はゼロになります。
  ・元のキャプチャに戻したい場合は「🎥 画面キャプチャに戻す」または左上の「📐」ボタンから復帰します。

【ショートカットキー】
  ・[F9] キー：現在アクティブな枠（青・黄・赤）のトリミング範囲を再指定できます。


--------------------------------------------------------------------------------
■ ファイル構成
--------------------------------------------------------------------------------
・timer_overlay.exe     : アプリ本体（わずか約25KB・単体動作）
・stop.bat              : 万が一の際に一撃で完全終了できる緊急停止スクリプト
・config.json           : 設定保存ファイル（初回起動時に自動生成）
・readme.txt            : 本説明書


--------------------------------------------------------------------------------
■ 設定の初期化（リセット）について
--------------------------------------------------------------------------------
トリミング範囲や表示位置を最初からやり直したい場合は、
同じフォルダにある「config.json」を削除してから「timer_overlay.exe」を起動すると、
初期状態（範囲選択モード）から再スタートできます。
