ゲーム（ブルーアーカイブ等）の戦闘画面右上にある**「残り時間（0.00s単位）」**などをリアルタイム（遅延約0.05ms/frame）にトリミングし、画面中央下など見やすい位置へ最前面・角丸枠なし（四隅完全透過）で表示するWindows用超軽量オーバーレイツールです。

## 主な特徴

- ⚡ **超低遅延リアルタイム表示**
  - ゲームの指定領域を遅延約0.05msで滑らかにキャプチャし、最前面にクリーン表示。0.00秒のカウントダウンも完全に追従します。
- 🖱️ **直感的な操作 ＆ 比率固定リサイズ**
  - 中央ドラッグで好きな場所へ移動（位置は自動保存）。枠がアクティブな時は**枠の端をドラッグしてアスペクト比を保ったまま自由に拡大・縮小**できます。
- 🎨 **多重起動（黄枠・赤枠）対応**
  - 右クリックから「黄枠」「赤枠」を追加可能。タイマー、HPバー、コストゲージなど、複数の箇所をそれぞれ独立した領域・倍率・更新レートで同時監視できます。
- 🖼️ **静止画読み込み ＆ 100%原寸保存**
  - キャプチャだけでなく攻略チャートや目標タイム表などの画像ファイル（PNG/JPG/BMP/GIF）を読み込んで最前面表示可能。また、現在表示されている領域を**100%原寸サイズのままワンクリックで画像保存**できます。
- 🖥️ **マルチモニター対応 ＆ 完全オフライン**
  - サブモニター上の領域指定や移動に完全対応。外部通信は一切ゼロの安全設計です。

## 使い方

1. **起動 & 範囲指定**:
   - `timer_overlay.exe` を起動すると画面が薄暗くなります。ゲーム画面のタイマー部分を**左ドラッグ**で囲むだけで設定完了です（4倍拡大ルーペ付き、`Esc` でキャンセル）。
2. **基本操作**:
   - **移動**: 枠の内側を左ドラッグ。
   - **リサイズ**: 枠をクリックしてアクティブにし、枠の端（四辺・四隅）をドラッグ（縦横比は完全固定）。
   - **メニュー**: 右クリックで多重起動、トリミング範囲再設定、表示倍率、更新レート、画像保存、静止画読み込みなどが選べます。
   - **終了**: アクティブ時に右上の [×] をクリック、または右クリック ➜「❌ アプリを終了」。

## 操作方法一覧

| 操作 / キー | 機能 | 説明 |
| :--- | :--- | :--- |
| **左ドラッグ（中央）** | 移動 | 枠内を掴んでお好みの位置へ自由に移動（位置は自動保存）。 |
| **端ドラッグ（端8px）** | 比率固定リサイズ | アクティブ時に枠端をドラッグしてアスペクト比完全固定で拡大・縮小。 |
| **右クリック** | 設定メニュー | 多重起動、倍率、FPS、画像保存、静止画読込、全終了などのメニュー。 |
| **多重起動** | 黄枠 / 赤枠 | 右クリックから黄枠・赤枠を追加表示（各枠は独立動作）。 |
| **💾 画像保存** | 100%原寸保存 | 右クリック ➜「現在のトリミング画像を保存」で100%原寸ファイル保存。 |
| **🖼️ 静止画読み込み** | 画像オーバーレイ | 右クリック ➜「静止画を読み込み...」から画像ファイルを選択して表示。 |
| **[📐] / F9** | 範囲の再設定 | クリックした枠のトリミング範囲を個別に再指定。 |
| **右上の [×]** | アプリの終了 | 右上の [×] をクリックして終了（メイン枠終了で全枠終了）。 |
| **stop.bat** | 緊急終了 | フォルダ内の `stop.bat` をダブルクリックすると一発で完全終了。 |

## ビルド方法

Windows標準の .NET Framework コンパイラ（`csc.exe`）を使用するため、Visual Studio や外部ツールのインストールは不要です。

```cmd
# リポジトリルートで build.bat を実行するだけです
build.bat
```
