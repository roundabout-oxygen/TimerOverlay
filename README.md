# Timer Overlay (ゲーム画面 残り時間 最前面オーバーレイ)

[![Version](https://img.shields.io/badge/version-v1.1.6-blue.svg)](VERSION)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)
[![Platform](https://img.shields.io/badge/platform-Windows%2010%20%2F%2011-lightgrey.svg)]()
[![Size](https://img.shields.io/badge/size-~26KB-success.svg)]()

ゲーム（ブルーアーカイブ等）の戦闘画面右上などにある**「残り時間（0.00s単位）」**をリアルタイム（遅延約0.05ms/frame）にトリミングし、画面中央下など見やすい位置へ最前面・角丸枠なし（四隅完全透過）で表示するWindows用超軽量オーバーレイツールです。

0.00秒単位のミリ秒カウントダウンも実画面と完全に一致して滑らかに追従します。  
インストール不要、外部DLL不要、**わずか約26KBの単一実行ファイル**で動作します。

## 主な特徴

- ⚡ **超低遅延・0.00s完全一致（ラグなし）**
  - Windowsネイティブグラフィックス（GDI / DWM）により、1フレームあたり **約0.05ms（秒間20,000フレーム相当）** の超高速処理を実現。ミリ秒単位の激しいカウントダウンも一切遅延なく実画面と一致します。
- 🪟 **邪魔にならない最前面・角丸四隅透過UI**
  - 余計なウィンドウ枠やタイトルバーを排除したクリーンなデザイン。
  - 四隅は完全透過となっており、ゲーム画面の上に青い角丸カードだけが綺麗に浮き出ます。
- 👁️ **アクティブ時のみボタン表示（非アクティブ時は自動非表示）**
  - クリックしてアクティブになっている時のみ、右上の [×] 閉じるボタンと左上の [📐] 再設定ボタンが表示されます。
  - 他のソフトを操作中（非アクティブ時）はボタンが完全に消え、トリミングしている領域が隅々までクリアに映ります。
- 🎨 **多重起動モード ＆ 各枠独立トリミング（青枠・黄枠・赤枠）**
  - 右クリックメニューの「多重起動」から「黄枠」「赤枠」を追加可能。
  - **各枠（青・黄・赤）は完全に独立したトリミング領域とサイズを持てます。**
  - 黄枠の [📐] ボタンを押せば黄枠だけが再設定され、青枠や赤枠には影響しません。「青枠にタイマー」「黄枠にHPバー」「赤枠にコストゲージ」等の同時表示が可能です。
  - それぞれ個別にドラッグ移動でき、右クリック「アプリを終了」で開いている全枠を一括終了できます。
- 🖱️ **マウスドラッグで自由配置 ＆ 位置自動保存**
  - オーバーレイウィンドウのどこを掴んでも、お好みの場所（画面中央下や端など）へドラッグ移動できます。移動した位置は自動保存され、次回起動時も同じ場所に表示されます。
- 📐 **直感的なSnipping Tool風範囲指定 ＆ 4倍拡大ルーペ（F9キー）**
  - 初回起動時や `F9` キーで、画面全体が暗転する範囲選択モードが起動。
  - ドラッグ中の範囲が鮮やかなシアン枠とサイズバッジ（○○ × ○○ px）でリアルタイムにハイライトされます。
  - カーソル横に **4倍拡大ルーペと赤クロスヘア** が追従するため、タイマーの枠にピクセル単位で正確に合わせられます。
- ❌ **確実に終了できる安心設計**
  - アクティブ時に右上に表示される [×] ボタンをクリックで終了。
  - **タスクバーにも常時アイコンが表示**されるため、タスクバー右クリック →「ウィンドウを閉じる」でも確実に終了できます。
- 📦 **驚異の超軽量サイズ（約26KB）＆ 完全オフライン**
  - 外部ランタイムやPython不要。Windows 10/11標準の .NET Framework 4.8 のみで動作。
  - 通信機能は完全ゼロ。外部接続やテレメトリ、API、個人情報の収集等は一切ありません。

## 使い方

### 1. ダウンロード & 起動
1. 上記の [**ダウンロードボタン**](https://github.com/roundabout-oxygen/TimerOverlay/raw/main/release/timer_overlay.exe) から **`timer_overlay.exe`** をダウンロードします。
2. インストーラーや追加のランタイムは一切不要です。ダブルクリックするだけで即座に起動します。

### 2. トリミング範囲の指定（初回起動時）
1. 起動すると画面全体が薄暗くなり「トリミング範囲指定モード」になります。
2. ブルアカの戦闘画面を開き、右上の「残り時間（0.00s）」の部分をマウスの**【左ドラッグ】**で囲んでください。
3. カーソル横の4倍拡大ルーペを確認しながら囲み、マウスを離すと範囲が保存され、画面中央下にオーバーレイが表示されます。
   - キャンセルしたい場合は `Esc` キーまたは右クリックを押します。

## 操作方法・ショートカットキー

| 操作 / キー | 機能 | 説明 |
| :--- | :--- | :--- |
| **左ドラッグ** | ウィンドウの移動 | オーバーレイ上のどこを掴んでも、お好みの位置へ自由に移動可能（移動先は自動保存）。 |
| **右上の [×]** | アプリの終了 | アクティブ時に右上に表示される赤い [×] をクリックすると終了します（サブ枠の場合はその枠のみ終了）。 |
| **タスクバー** | ウィンドウを閉じる | タスクバーのアイコンを右クリック →「ウィンドウを閉じる」でも確実に終了できます。 |
| **右クリック** | 設定メニュー | 各枠のトリミング再設定、多重起動（黄枠・赤枠）、表示倍率、更新FPS、中央リセット、全終了などのメニューが開きます。 |
| **多重起動** | 黄枠 / 赤枠 | 右クリックメニューから選択すると、黄枠・赤枠オーバーレイを少し下に追加表示します。各枠は完全に独立した領域・サイズに設定可能。 |
| **F9 / [📐]** | 範囲の再設定 | クリックした枠（またはアクティブな枠）のトリミング範囲を個別に再指定できます（他枠には影響しません）。 |
| **stop.bat** | 緊急終了 | フォルダ内の `stop.bat` をダブルクリックすると、本アプリを一発で完全終了できます。 |

## ビルド方法

Windows標準の .NET Framework コンパイラ（`csc.exe`）を使用するため、Visual Studio や外部ツールのインストールは不要です。

```cmd
# リポジトリルートで build.bat を実行するだけです
build.bat
```

スクリプト内部で以下のコマンドが実行され、`release\timer_overlay.exe` が生成されます：

```cmd
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /target:winexe /platform:x64 /optimize+ /win32icon:src\app.ico /lib:C:\Windows\Microsoft.NET\Framework64\v4.0.30319\WPF /r:System.dll,System.Core.dll,System.Drawing.dll,System.Windows.Forms.dll,WindowsBase.dll,PresentationCore.dll,PresentationFramework.dll,System.Xaml.dll /out:release\timer_overlay.exe src\App.cs
```
